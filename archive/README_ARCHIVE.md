# الأرشيف التفصيلي التاريخي

يحفظ هذا المجلد الملفات التفصيلية الأصلية التي سبقت إعادة التنظيم v0.5.0. **ليست هذه الملفات مرجع العمل اليومي ولا تُحمّل تلقائيًا على الوكلاء.** افتح وثيقة محددة فقط عند الحاجة إلى تفصيل متخصص أو مراجعة تاريخية.

- `original-detailed-docs/docs/PROJECT_BLUEPRINT.md`: المخطط التفصيلي السابق.
- `original-detailed-docs/docs/DECISION_TRACEABILITY_Q1-Q247.md`: سجل إعادة بناء القرارات التاريخية، وليس تفريغًا حرفيًا.

- بقية الملفات: خطط الاختبار والتدقيق والخصوصية والقانون والأعمال والتقنية والتشغيل، محفوظة للرجوع.
- `prompts/`, `templates/`, `source-project/`: قوالب ومساعدات العمل السابقة، محفوظة كمرجع.
