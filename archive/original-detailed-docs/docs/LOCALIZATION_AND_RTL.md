# العربية والتوطين وRTL

- العربية هي اللغة الافتراضية وتصمم الواجهة بها من البداية.
- اللغة منفصلة عن اتجاه الواجهة، تنسيق المنطقة، لغة الوثيقة، ولغة بيانات الزبون.
- موارد نصية بمفاتيح ثابتة؛ لا نصوص ظاهرة مبعثرة داخل منطق الأعمال.
- صياغة عربية طبيعية ومهنية، لا ترجمة حرفية.
- RTL يشمل القوائم والنماذج والجداول والحوار والطباعة، لا اتجاه الصفحة فقط.
- استخدم CSS logical properties مثل margin-inline-start.
- اعكس الأيقونات الاتجاهية فقط.
- اختبر النص المختلط: عربي/فرنسي/أرقام/باركود/بريد/URL.
- بيانات الأرقام والتواريخ تبقى بقيم معيارية في التخزين وتُنسق للعرض.
- دعم اتصال الحروف العربية في PDF والطباعة والخطوط.
- تغيير لغة الواجهة لا يغيّر البيانات التجارية.
- اختبارات قبول: واجهة عربية، واجهة LTR مستقبلية، طباعة PDF، باركود، بريد إلكتروني داخل RTL، تغيير اللغة دون فقد الحالة.
