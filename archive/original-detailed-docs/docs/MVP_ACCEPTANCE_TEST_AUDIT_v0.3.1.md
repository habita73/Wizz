# تدقيق حالات قبول MVP — v0.3.1

## ما أُنجز
- حُوّل نطاق MVP المقترح إلى 24 حالة اختبار ذات معرّفات ثابتة.
- فُصلت الأولويات P0/P1 عن حالات تعتمد على أجهزة أو قرارات لم تُحسم.
- أضيفت قواعد PASS/FAIL/BLOCKED ومعيار قبول مبدئي.
- غُطيت سلامة البيع والحسابات، العمل دون اتصال، النسخ والاستعادة، الصلاحيات، سجل التدقيق، الذكاء الاصطناعي، الخصوصية، عدم تكرار العمليات، الاستيراد، المخزون الاختياري، التصدير، الترخيص والتحديث.

## حدود التدقيق
هذه حالات قبول مقترحة وليست نتائج اختبار. لم يُنفذ برنامج ولم يُختبر أي جهاز. معايير الأداء الرقمية والتوافق الفعلي والأحكام القانونية ما زالت بحاجة إلى تحقق.

## القرار المطلوب
اعتماد حالات القبول هذه أو تعديلها قبل استخدامها كشرط رسمي للقبول. لا يمنح هذا المستند إذنًا بالبرمجة.
