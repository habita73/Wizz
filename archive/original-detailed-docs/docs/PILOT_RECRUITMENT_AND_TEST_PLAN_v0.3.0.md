# خطة الاختبار والتجربة الميدانية — Vent au comptoir

- الإصدار: 0.3.0
- الحالة: PROPOSED — لم تُعتمد تجربة ميدانية مع تاجر بعد.
- المرجع: PROJECT_RULES.md وقرارات Q1–Q247 ونطاق MVP المقترح.

## 1. الوضع الحالي
لا يوجد حاليًا تاجر أو محل متاح لتجربة النسخة الأولى. هذا لا يمنع مواصلة التحليل والتصميم، لكنه يمنع الادعاء بأن تجربة ميدانية حقيقية قد نُفذت أو اعتماد المنتج للإطلاق العام.

## 2. ترتيب الاختبارات دون تاجر
1. **اختبارات تصميمية:** حالات استخدام مكتوبة للبيع، المرتجعات، الدفع الجزئي، التصحيح، والصلاحيات.
2. **اختبارات داخلية ببيانات اصطناعية:** بيانات تجار ومنتجات وفواتير وهمية بوضوح، لا بيانات أشخاص حقيقيين.
3. **اختبارات تقنية للأجهزة:** تُجرى عندما تتوفر أجهزة محددة، ولا يُفترض توافق طابعة أو قارئ باركود دون اختبار.
4. **اختبارات الانقطاع والاستعادة:** العمل دون إنترنت، إعادة التشغيل، النسخ الاحتياطي والاستعادة، ومنع تكرار العمليات.
5. **اختبارات الذكاء الاصطناعي:** طلبات صحيحة وغامضة وخطرة، التحقق من الصلاحيات والتأكيدات وعدم الادعاء بنجاح عملية لم تُنفذ.
6. **تجنيد تاجر تجريبي:** قبل الإطلاق العام، البحث عن تاجر متطوع مناسب وتحديد نطاق التجربة ومدة المتابعة وطريقة تسجيل الملاحظات.

## 3. شروط اختيار التاجر التجريبي لاحقًا
- نشاط صغير قريب من نطاق MVP.
- استعداد لتجربة محدودة وتقديم ملاحظات دورية.
- قبول استخدام بيانات اختبار أو بيانات تشغيل مصرح بها مع حماية الخصوصية.
- إمكانية اختبار سير البيع والأجهزة الفعلية.
- موافقة واضحة على حدود التجربة وعدم التعامل معها كمنتج نهائي مضمون.

## 4. بوابة الانتقال
لا تُعلن الجاهزية للإطلاق العام حتى:
- اجتياز اختبارات القبول الأساسية وسلامة البيانات.
- إثبات النسخ الاحتياطي والاستعادة عمليًا.
- اختبار وضع عدم الاتصال والتعامل مع الأخطاء.
- التحقق من الوثائق التجارية والقواعد القانونية ذات الصلة بواسطة مختص عند الحاجة.
- تنفيذ تجربة محدودة مع مستخدم فعلي، أو توثيق قرار صريح ومسبب بشأن أي بديل؛ ولا يُعد الاختبار الداخلي بديلًا مكافئًا تلقائيًا.
- موافقة صاحب المشروع على الانتقال إلى المرحلة التالية.

## 5. ما لا يعنيه هذا القرار
- لا يعني حذف التجربة الميدانية من الخطة.
- لا يعني البدء بالبرمجة أو شراء أجهزة أو تحمل تكاليف دون موافقة.
- لا يثبت توافق البرنامج مع طابعة أو قارئ باركود بعينه.
- لا يغيّر نطاق المنتج الكامل أو يؤجل أي وحدة نهائيًا؛ إنه ترتيب اختبار فقط.

## 6. الحالة التالية
المتابعة الآن تكون بإعداد حالات اختبار قبول MVP وبيانات اصطناعية، بالتوازي مع إعداد خطة عملية للعثور على تاجر تجريبي قبل الإطلاق العام.
