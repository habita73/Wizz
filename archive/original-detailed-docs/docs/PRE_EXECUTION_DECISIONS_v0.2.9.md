# قائمة الحسم قبل التنفيذ — Vent au comptoir

- الإصدار: 0.2.9
- الحالة: **PLANNING — لا إذن بالتنفيذ**
- الغرض: حصر القرارات المفتوحة بعد اعتماد نطاق MVP دون إعادة فتح قرارات Q1–Q247 المحسومة.

## 1. ما تم اعتماده
- نطاق MVP ومعايير القبول الواردة في `MVP_SCOPE_PROPOSAL.md` كخط أساس للتخطيط.
- اتجاه المنتج: Windows Desktop أساسًا، محلي أولًا، واجهة عربية RTL، .NET/C# وBlazor وPostgreSQL كاتجاه عام مع تحقق التفاصيل التقنية.
- البيع يعمل دون إنترنت؛ المخزون قابل للتعطيل؛ AI حاضر منذ البداية مع ضوابط الصلاحيات والخصوصية.

## 2. قرارات مفتوحة فقط
1. **قطاع التجربة الأول:** يحدد بناءً على الوصول إلى تجار حقيقيين وسهولة اختبار البيع والمخزون والطباعة. لا يُفترض قطاع بعينه دون اختيار المستخدم.
2. **بيئة الاختبار:** جهاز Windows فعلي ومواصفاته وإصدار النظام، وطراز قارئ الباركود والطابعة المتاحين. لا يُعلن التوافق قبل الاختبار.
3. **التخزين والتثبيت المحلي:** مقارنة خيارين أو ثلاثة فقط من حيث الاستقرار والنسخ والاستعادة والتحديث وسهولة الدعم؛ القرار النهائي بعد نموذج تقني اختباري مصرح به.
4. **AI:** اختبار قصير لمساعد عربي على مجموعة مهام تجارية ممثلة، ومقارنة جودة/خصوصية/تكلفة/عمل دون إنترنت بين خيار محلي وخيار سحابي أو هجين. لا تُختَر أوزان أو مزود نهائي قبل القياس.
5. **الوثائق القانونية:** تثبيت الحد الأدنى من مستندات MVP بعد مراجعة مختص جزائري؛ لا يُدّعى اعتماد ضريبي أو توافق رسمي قبل التحقق.
6. **الفريق والميزانية والمدة:** تقدير بعد تثبيت القطاع والجهاز وتجارب المخاطر التقنية؛ يجب أن يشمل التحليل والتطوير والاختبار والتغليف والنسخ والاستعادة وتجربة ميدانية ودعمها، لا البرمجة وحدها.

## 3. بوابات الخروج من مرحلة التوثيق
- [ ] اختيار قطاع التجربة وعدد التجار/الأجهزة.
- [ ] حصر الأجهزة المتاحة فعليًا وتوثيق طرازاتها.
- [ ] اعتماد قرار تقني مختصر مدعوم باختبار، بعد إذن صريح بإجراء النموذج الاختباري.
- [ ] توثيق المستندات والضرائب المطلوبة بعد مراجعة مختص.
- [ ] ميزانية ومدة وفريق ومخاطر واقعية.
- [ ] تحويل معايير القبول إلى متطلبات واختبارات قابلة للتتبع.
- [ ] موافقة صريحة منفصلة من Farid على بدء التنفيذ.

## 4. قاعدة العمل
لا تُطرح أسئلة جديدة إلا عندما يكون جواب المستخدم ضروريًا لاتخاذ قرار تجاري أو نطاقي. أما التفاصيل التقنية التي يمكن حسمها باختبار، فتُعرض كخطة اختبار قصيرة بدل سلسلة أسئلة نظرية.
