# استراتيجية الاختبار — تصميم فقط

اختبر قواعد المجال، المعاملات، البيع والمخزون، التكرار والتعارض، RTL والطباعة، الصلاحيات، استعادة النسخ، AI، التكاملات، تثبيت وتحديث Windows.

اختبارات حاسمة:
- البيع يسجل مرة واحدة.
- فشل حركة المخزون يلغي المعاملة المتكاملة.
- تكرار حدث لا يكرر البيع.
- انقطاع الإنترنت لا يمنع البيع المحلي.
- تعارض السعر لا يُحسم بصمت.
- لا يستطيع متجر قراءة بيانات متجر آخر.
- AI لا يستدعي وظيفة غير مسموحة.
- لا يرسل بريد دون التفويض المطلوب.
- PDF عربي صحيح.
- استعادة النسخ مجربة.
- انتهاء اشتراك لا يحذف البيانات.
- تعطل AI لا يعطل المبيعات.

لا تعتبر الميزة جاهزة لمجرد أن الواجهة تظهر؛ يلزم تحقق معايير القبول.
