# سير العمل بين ChatGPT Project وCodex وIDE والوكلاء

## الآن
يمكننا مواصلة التوثيق بهذه الحزمة دون Workspace/Codex. احفظها محليًا. عند توفر Codex، ضع الملفات في مستودع Git وافتح المستودع. لا تفترض انتقال سجل المحادثة تلقائيًا.

## Git
- main للوثائق المعتمدة.
- فروع للمهام الكبيرة.
- لا أسرار أو بيانات متجر حقيقية.
- راجع diff قبل الدمج.
- لا دمج لتغيير يناقض قرارًا معتمدًا دون ADR.

## الوكلاء
- عيّن ملفات محددة لكل وكيل.
- لا تعديلات متزامنة على الملف نفسه.
- اقرأ AGENTS.md أولًا.
- اطلب تقرير الملفات والقرارات والمخاطر.
- لا تستخدم ذاكرة الوكيل بدل الوثائق.

## عند فتح Codex
1. افتح المستودع.
2. اطلب مراجعة توثيق فقط.
3. ارفض أي إنشاء كود أو نشر قبل إذن Farid.
4. راجع كل التغييرات.
