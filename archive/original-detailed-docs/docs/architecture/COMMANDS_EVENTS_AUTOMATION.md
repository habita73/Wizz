# الأوامر والأحداث والأتمتة

## تمييز المفاهيم
- Domain Event: حدث وقع، مثل SaleRegistered.
- Command: طلب عمل، مثل CreateDeliveryNoteDraft.
- Scheduled Job: مهمة مجدولة.
- Integration Event: رسالة نقل إلى نظام خارجي.

## القرار المقترح
محرك داخلي بـ .NET هو الأساس. Telegram وn8n وWebhooks تكاملات اختيارية. لا تعتمد المبيعات على أي منها.

## الأمان
- ربط موثق بين حساب القناة والمستخدم والمتجر.
- صلاحيات أقل ما يمكن، allowlist للوظائف.
- موافقة للإجراءات الحساسة.
- تحقق من التوقيع/المصدر ومعدل الطلبات ومنع replay.
- لا تعرض قاعدة البيانات للإنترنت.
- سجل حالة التنفيذ والنتيجة.
- لا تدّع نجاح إرسال بريد قبل التأكيد.
- اعتبر رسائل الخارج ونتائج AI مدخلات غير موثوقة.

## التكلفة والترخيص
محرك داخلي لا يحتاج اشتراك منصة لكنه يحتاج تطويرًا وصيانة. Telegram يحتاج اتصالًا واستضافة. n8n ذاتي الاستضافة لا يعني أن كل تضمين/إعادة بيع تجاري مسموح؛ يجب فحص الترخيص الساري. البريد وSMS وAI السحابي قد تكون مدفوعة.
