## 2. القرارات التي يلزم حسمها قبل التنفيذ

هذه هي القرارات عالية الأثر فقط؛ لا حاجة إلى فتح تفاصيل منخفضة الأثر الآن:

1. **نموذج تشغيل Windows:** اختيار مرشح واحد للتجربة التقنية بين تطبيق سطح مكتب مضمّن/مغلّف مع واجهة Blazor، أو واجهة ويب محلية تُفتح من المتصفح، مع إثبات الطباعة والعمل دون إنترنت.
2. **حدود قاعدة البيانات:** تحديد وضع قاعدة البيانات في التثبيت المنفرد وفي وضع خادم المحل، وكيف تتم الترقية والنسخ والاستعادة.
3. **نموذج البيانات الأولي:** الكيانات الأساسية وعلاقاتها، وسجل العمليات غير القابل للمحو الصامت، وسياسات التزامن لكل مجال.
4. **الطباعة والباركود:** اختبار فعلي لطابعة وقارئ متاحين قبل تثبيت قرار تقني نهائي. لا يوجد جهاز تجريبي معروف حاليًا.
5. **الذكاء الاصطناعي الأولي:** اختيار مهمتين أو ثلاث ذات قيمة تجارية وقابلة للاختبار، ثم مقارنة خيار محلي وسحابي وفق الجودة والخصوصية والتكلفة والاتصال؛ لا يُحسم اسم النموذج بالتخمين.
6. **التوزيع والتحديث:** شكل الحزمة والتثبيت والتحديث والترحيل والتراجع دون فقد بيانات.
7. **متطلبات الامتثال:** مراجعة مختص للنماذج القانونية وقواعد الفوترة والضرائب المطبقة على فئة العميل قبل ادعاء المطابقة.

## 3. ما يمكن تأجيله

- اختيار مزود سحابي بعينه، أو مزود ذكاء اصطناعي بعينه، ما لم تفرضه تجربة التحقق.
- تفاصيل المزامنة متعددة الفروع المتقدمة، والتحليلات التنبؤية، ومحرر الأتمتة المرئي.
- تصميم كل الوحدات المتقدمة التي لا تدخل MVP، مع إبقائها في المخطط الشامل.
- أسعار الباقات وحدودها التجارية النهائية إلى حين تقدير تكاليف التشغيل والدعم وتجربة السوق.

## 4. بوابة الانتقال التالية

لا يبدأ التنفيذ إلا بعد:

- اعتماد نطاق MVP ومعايير قبوله صراحةً.
- اعتماد قرار تقني مسبب للتشغيل على Windows بعد نموذج تحقق محدود؛ إنشاء نموذج إثبات تقني نفسه يحتاج إذن التنفيذ الصريح.
- تثبيت خطة البيانات والنسخ والاستعادة وسياسات التزامن.
- اعتماد نطاق مهام الذكاء الاصطناعي الأولية وضوابطها.
- تقدير واقعي للفريق والمدة والتكلفة.
- مراجعة قانونية للنقاط التي تتطلب تفسيرًا مهنيًا.

## 5. ملاحظة حوكمة

هذه الوثيقة لا تعتمد القرارات نيابةً عن صاحب المشروع، ولا تعدّل الحالة `APPROVED` لأي قرار سابق. كل تفصيل جديد يظل `PROPOSED` أو `NEEDS-VALIDATION` حتى اعتماده أو التحقق منه. لم تُنشأ أي مشاريع برمجية ولم تُشغّل اختبارات تقنية.
