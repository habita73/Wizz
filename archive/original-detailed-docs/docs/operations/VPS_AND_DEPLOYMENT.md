# VPS والنشر — مؤجل

المالك يملك VPS يمكن استخدامه لاحقًا، لكن لا يوجد إذن بإعداده أو نشر شيء عليه الآن.

## استخدامات محتملة لاحقًا
API سحابية، مزامنة، هوية وربط متاجر، اشتراكات، نسخ احتياطي مشفر، بوابة أوامر بعيدة، مراقبة.

## قواعد
- لا تخزن بيانات المتاجر قبل تحديد سياسة الخصوصية ومكان الاستضافة.
- لا تفتح PostgreSQL المحلي للإنترنت.
- اتصالات المتجر بالسحابة عبر قناة آمنة.
- الأسرار خارج Git.
- توثيق النسخ والاستعادة والتحديث والمراقبة.
- لا إعداد أو نشر قبل إذن منفصل من المالك.

## لاحقًا
تحقق من موارد VPS ونظام التشغيل والنطاقات وTLS والشبكات والأسرار والاحتفاظ والتكاليف.
