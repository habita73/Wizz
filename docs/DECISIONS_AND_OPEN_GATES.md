## 1. القرارات الحاكمة

| ID | القرار | الحدود |
|---|---|---|
| D-01 | لا برمجة أو إنشاء مشروع قابل للبناء قبل إذن صريح | يشمل scaffolding وmigrations وprototype تشغيلي والنشر وVPS |
| D-02 | Windows Desktop أساس البيع | توافق الطرازات يحتاج اختبارًا فعليًا |

| D-06 | المنتج وحدات قابلة للتهيئة | يمكن البيع فقط؛ المخزون ووحدات أخرى اختيارية |
| D-07 | AI موجود في كل عرض بمستويات مختلفة | الأسعار والحصص والنماذج لم تُحسم |
| D-08 | العربية وRTL أساس؛ اللغات مستقلة لكل قناة | دعم اللهجات/الصوت يحتاج تقييمًا |
| D-09 | الاتجاه العام .NET/C# وBlazor وPostgreSQL | تفاصيل التنفيذ تحتاج تحققًا |
| D-10 | جهاز مستقل/خادم محلي/سحابة اختيارية | لا يعني أن المزامنة الإنتاجية ضمن MVP |
| D-11 | لا Last Write Wins عام | سياسة التعارض بحسب المجال |
| D-12 | AI عبر أدوات مقيدة لا SQL/shell حر | صلاحيات التطبيق والتأكيدات هي المرجع |
| D-13 | ترخيص هجين وبقاء البيانات والنواة المحلية بعد الاشتراك | تفاصيل الباقات والسعر مؤجلة |
| D-14 | بيانات التاجر قابلة للتصدير | حفظ العلاقات قدر الإمكان، لا ضمان نقل كل وظيفة |
| D-15 | النسخ والاستعادة والتدقيق والجودة متطلبات أساسية | لم تُختبر فعليًا بعد |
| D-16 | لا ادعاء امتثال أو توافق قبل التحقق | مختص جزائري واختبار أجهزة فعلية حسب الحاجة |

## 4. القضايا التجارية المفتوحة

الأسعار وأسماء الباقات والحصص وحدود AI وتكلفة التشغيل والدعم، وفترات السماح والترخيص التفصيلية، وقنوات الدفع/التوصيل والتكاملات الفعلية. لا تُخترع أرقام قبل تجربة سوق وعروض أسعار أو تقديرات معلنة الافتراضات.

## 5. حالات القرار

`APPROVED` قرار وافق عليه المستخدم؛ `PROPOSED` اقتراح؛ `ASSUMPTION` افتراض مؤقت؛ `NEEDS-VALIDATION` يحتاج تحققًا؛ `DEFERRED` مؤجل لا ملغى؛ `REJECTED` مرفوض. عند تعارض مرجع نشط مع ملف تاريخي، لا يُحسم بالتخمين. سجل Q1–Q247 محفوظ في الأرشيف وهو إعادة بناء تاريخية، لا تفريغ حرفي كامل.
