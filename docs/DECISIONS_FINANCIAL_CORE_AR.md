## 3. سجل إذن محدود — نواة الحسابات المالية

- **سجل الإذن المحدود السابق:** منح فريِد إذنًا محدودًا ومحددًا لإنشاء `VentAuComptoir.sln` وهيكل المشاريع الضروري (`src/`, `tests/`) لمشروع `VentAuComptoir.Domain` وتنفيذه مع اختباره. شمل هذا الإذن النواة المالية فقط: `Money.cs`، `SaleLine.cs`، `SaleCalculator.cs`، `SaleTotals.cs`، و`SaleCalculationException.cs`.
- هذا الإذن **لا يعني** فتحًا لبقية التنفيذ، ولا يُعد إذنًا عامًا ببرمجة باقي النطاق.
- **غير مشمول بهذا الإذن:** إنشاء قاعدة البيانات أو إعدادها، أو إضافة migrations، أو إنشاء واجهة مستخدم، أو تنفيذ وحدات أخرى، أو نشر، أو إجراء تغييرات في البنية التحتية.
- **G-03** ما زال مفتوحًا — لم يؤذن بالتنفيذ. أي دراسة أو اختبارات تحقق خاصة باختيارات التخزين والتثبيت على Windows تحتاج إلى إذن صريح مستقل.
- **G-08** ما زال غير ممنوح. هذا التصحيح التوثيقي لا يمنح G-08 ولا يوسّع نطاق التنفيذ.
- يحتفظ فريِد بسلطة القرار النهائية في المسائل المعمارية والتجارية. أي توسع في النطاق يحتاج إلى موافقته الصريحة.

## 7. عقد الخرج المعتمد — `SaleCalculator` / `SaleTotals`

**العقد التوثيقي المعتمد (D4) — مرجع للمرحلة الحالية:**

1. **المبالغ الخمسة** بحد أقصى **منزلتين عشريتين**.
2. `Subtotal >= 0`.
3. `0 <= Discount <= Subtotal`.
4. `Total = Subtotal - Discount`.
5. `0 <= Paid <= Total`.
6. `Remaining = Total - Paid >= 0`.

**توضيحات تكميلية:**
- لا يدخل أي حقل **مبلغ مُسلَّم** ولا **باقي (الرند)** في `SaleTotals`.
- `Paid` هو **المبلغ المطبق على البيع**؛ `Remaining` هو **الرصيد المتبقي (المستحق)**.
- **إجمالي صفري** (`Total = 0`، إذن `Paid = 0` و `Remaining = 0`) نتيجة **صحيحة** (خصم كلي أو سطور مُقرَّبة إلى صفر).
- **التنفيذ الحالي:** العقد تُطبِّقها **المصنع** (`SaleCalculator`)، و `SaleTotals` **سجل عام موضعي (`public positional record`)** بلا حارس ذاتي. العقد إذن، راهنًا، **اتفاقية مصنع**، لا ضمانة نوع.
- **الفرض المستقبلي المحتمل للثوابت مباشرة في النوع `SaleTotals`** يبقى **قرارًا تقنيًا منفصلاً**، غير محسوم، غير مصرح به في هذه المرحلة.
