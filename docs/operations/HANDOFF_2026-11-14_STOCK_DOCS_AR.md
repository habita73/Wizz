## 2. القرارات المعتمدة والمطبقة

- **D-21 / D-22:** إذنان محدودان لتنفيذ H-05 وH-02.
- **D-23:** المستندات مصدر الحقيقة الوحيد؛ الرصيد ذاكرة مؤقتة؛ لا جدول حركات ثانٍ؛ اتجاه اعتماد أحادي.
- **D-24:** التعديل الرجعي فقط في وردية الكاشير الحالية غير المغلقة؛ بعده مستند تصحيح. الإغلاق = وردية كاشير
  ويجمّد إجمالياتها. اليوم القديم غير المغلق لا يُعدَّل.
- **D-25:** الجرد والإتلاف مستندان (رقم، تاريخ، مستخدم، سبب).
- **D-26:** الترقيم `{CODE}-{YYYY}-{SEQ}` بتسلسل مستقل لكل (متجر، نوع، سنة)، سنة 2/4 والافتراضي 4.
- **D-27:** فصل `DocumentDate` عن `CreatedAt` والسماح بالتاريخ الرجعي.
- **D-28:** الترحيل المزدوج (إعادة بناء + افتتاحي اصطناعي بفارق الوصول) مع وسم وتحقق.
- **D-29:** لا حذف نهائي؛ التعطيل بدل الحذف.
- **توضيح D-20:** «سجل حركة لكل تغيير» = مستند مصدر واحد، لا سجل ثانٍ. «لا إعادة حساب رجعي» = قاعدة D-24.
